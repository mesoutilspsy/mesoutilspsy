Ouvrir index.html après décompression de l’ensemble du dossier.
Sevrage bzd est disponible dans Protocoles ttt, sur l’accueil et dans le menu.
Arrêts et les autres outils de la version précédente sont conservés.

Module intégré : version consultation 5.0 fournie le 8 novembre 2026.
Conserver sevrage-bzd.js avec index.html. Les calculs et les bibliothèques
PDF/Word sont embarqués ; aucun téléchargement de bibliothèque à l’utilisation.
Les sources externes s’ouvrent uniquement à la demande.

Fonctions : décroissance d’une molécule, relais de plusieurs benzodiazépines,
présentations françaises, calendrier, synthèse et document patient PDF/Word.
Les calculs et les exigences de relecture du module autonome sont conservés.
Les fichiers de paramètres v3/v4/v5 restent importables dans la rubrique
Paramètres de l’ancien module autonome.

Enregistrer / Reprendre dans le bandeau du site conserve les paramètres dans
un fichier local. À la reprise, les confirmations cliniques sont à refaire et
les propositions sont à recalculer, comme dans le module autonome. Changer
d’outil conserve la préparation en cours pendant cette session. Pas de
sauvegarde automatique ; un rechargement efface les saisies non enregistrées.

L’identité commune est proposée dans un champ vide, et reste modifiable dans
le module. L’en-tête professionnel suit le médecin du bandeau lorsque le nom
n’a pas été personnalisé. Les exemples fictifs gardent leur propre identité.
Relire l’identité, l’en-tête et les doses avant de remettre un document.
